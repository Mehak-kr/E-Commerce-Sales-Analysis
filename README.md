# 🛒 E-commerce Sales Insights Dashboard  

An interactive Power BI dashboard designed to analyze and visualize e-commerce sales performance — focusing on customer behavior, product trends, gender-based insights, and monthly sales variations.  

---

## 📝 Project Overview  
The **E-commerce Sales Insights Dashboard** provides a comprehensive, data-driven view of key sales metrics. It enables businesses to monitor performance, identify top customers and products, and uncover trends that drive decision-making.  

This project demonstrates the end-to-end data analysis process — from data extraction and cleaning in Python and MySQL, to interactive visualization and reporting in Power BI.

## 💻 Tech Stack  
This project was built using the following tools and technologies:  
- 🐍 Python (pandas, matplotlib, seaborn)** – For data cleaning, preprocessing, and exploratory analysis.  
- 🗃️ MySQL** – For structured data storage, querying, and relational analysis.  
- 📊 Power BI Desktop** – Main visualization platform used to build the interactive dashboard.  
- ⚙️ Power Query** – For data transformation and data modeling.  
- 🧮 DAX (Data Analysis Expressions)** – For calculated measures and KPIs.  
- 📁 File Formats** – `.pbix` (Power BI file), `.sql` (database schema), `.png` (dashboard preview).  

---

## 📂 Data Source  
**Source:** [E-commerce Sales Dataset – Kaggle](https://www.kaggle.com/datasets/berkayalan/ecommerce-sales-dataset)  

The dataset includes:  
- Customer IDs and demographic details (age, gender)  
- Basket-level transactions  
- Product details and quantities sold  
- Time-based purchase records

## ⭐ Key Objectives & Highlights  

### • Business Problem  
E-commerce businesses often deal with large volumes of transactional data, making it challenging to quickly identify top-performing products, loyal customers, or monthly sales patterns.  

### • Project Goal  
To develop a **data-driven, interactive dashboard** that:  
- Highlights key sales and customer performance metrics.  
- Analyzes sales trends by gender, age group
